DIANA CARDPUTER — RESTORE POINT (2026-09-17)
============================================
This is a snapshot of the SOURCE for the version where the VOICE works again
(Gemini Live native-audio TTS, no 10/day cap) and the speaker no-sound bug is fixed
(speakerMode() hard re-inits the I2S). Push-to-talk only (hold TAB), no auto-listening.

TO RESTORE (if you break the code):
  1. Close the editor / stop any build.
  2. From the project root "cardputer Diana", copy these folders back over the broken ones:
       - src\           (all the .cpp/.h)
       - platformio.ini
       - tools\  sdcard\  partitions\  README.md
     e.g. in a terminal at the project root:
       cp -r backups/working-voice-2026-09-17/src ./           (Git Bash)
     or in PowerShell:
       Copy-Item -Recurse -Force backups\working-voice-2026-09-17\src .
  3. Rebuild + flash:
       pio run
       pio run -t upload --upload-port COM3

NOTE: the .pio\ build folder is NOT backed up (it is regenerated automatically by
`pio run`). Only source is saved here, which is all you need.
